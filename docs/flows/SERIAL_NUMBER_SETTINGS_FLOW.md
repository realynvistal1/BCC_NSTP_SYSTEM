# Serial Number, Certificate, and Settings Flow

## ROTC/CWTS Admin Serial Number
1. Open Serial Number.
2. System lists approved students and loads MS/CWTS 1 and 2 grades.
3. Student is Eligible only when both Level 1 and Level 2 grades exist, matching the old source logic.
4. Certificate Settings must be complete before serial assignment.
5. Admin enters the official serial number and clicks Assign & Generate Certificate.
6. System checks eligibility, duplicate serial numbers, and settings.
7. Serial number is stored and the certificate becomes available.
8. Admin may download the generated certificate PDF.

## Certificate Settings
ROTC: Academic Year, issuance date, Commandant, School Registrar, optional signature images.
CWTS: Academic Year, issuance date, NSTP Coordinator, BCC President, Municipal Mayor, optional signature images.

## Student Serial Number
If no serial has been generated, the student sees Certificate is not yet available. Once generated, the official serial number and Download Certificate PDF button appear.

## Settings
Student: Student Profile, Appearance, Change Password.
ROTC Admin/CWTS Admin/NSTP Director: Appearance and Change Password.
