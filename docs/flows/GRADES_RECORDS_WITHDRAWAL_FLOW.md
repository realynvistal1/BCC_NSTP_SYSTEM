# Grades, View Records, Reports, and Advance Course Withdrawal

## Grades
- ROTC Admin and CWTS Admin see approved students only.
- Filters: NSTP/MS/CWTS level, school year, year level, search.
- Summary: Total Students, Graded, Ungraded.
- Encode/View Edit opens one student modal.
- NSTP 1 and NSTP 2 are handled independently.
- NSTP 2 fields are disabled until the student has an approved Level 2 enrollment.
- Midterm and Final Term must be 1.00 to 5.00.
- Average = (Midterm + Final Term) / 2.
- 1.00 to 3.00 = Passed; above 3.00 = Failed.
- Student Grades page is read-only.

## View Records
- ROTC/CWTS Admin sees approved enrollment-cycle records.
- Filters: search, level, school year.
- Download Excel exports the currently filtered records.
- View Details contains Personal Information, Enrollment and Assignment, Grade, Attendance Summary and detailed attendance rows, Serial/Certificate Information, and ROTC withdrawal history when applicable.

## Advance Course Withdrawal
- Only ROTC students currently enrolled in Advance Course can submit a request.
- Duplicate pending requests are blocked.
- Student can see Pending/Approved/Rejected status and admin remarks.
- ROTC Admin filters All/Pending/Approved/Rejected.
- Approve removes Advance Course status and automatically places the student back into the regular battalion/company/platoon roster using the same slot rules (male Battalion 1; female Battalion 2; four platoons per company; max 37 per platoon).
- Reject requires an in-app admin remark.
